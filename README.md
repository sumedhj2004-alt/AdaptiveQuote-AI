# AdaptiveQuote-AI 🤖

### AI-Powered Transaction Risk Assessment & Decision Support System

AdaptiveQuote-AI is an end-to-end AI system that combines **Machine Learning, FastAPI, PostgreSQL, RAG, LLM-based AI Agents, Human Feedback, and Model Versioning** to assess financial transaction risk and support business decisions.

The system doesn't stop at prediction. It creates a complete feedback loop where **AI analysis → human review → feedback dataset → model evaluation → safe retraining → model versioning** can continuously improve the system.

## 🚀 Key Features

* 🔍 ML-based transaction risk detection
* 📊 Risk score and LOW / MEDIUM / HIGH classification
* ⚡ FastAPI REST API
* 🗄️ PostgreSQL database integration
* 🤖 AI Agent using Ollama / Llama
* 📚 RAG-based policy retrieval with ChromaDB
* 👤 Human review and feedback system
* 🔄 Feedback-driven model retraining
* 🛡️ Safe model promotion using evaluation metrics
* 📦 Model versioning and registry
* 📈 Interactive Streamlit dashboard
* 🔗 End-to-end AI + Data + API workflow
